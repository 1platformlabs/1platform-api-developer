# Seguridad de webhooks

Cada webhook se firma con HMAC-SHA256 usando el `webhook_secret` de su espacio de
trabajo, que se entrega una sola vez: al registrar el primer dominio o al rotarlo. Verifique la firma **antes** de confiar en el contenido.

## Esquema de firma

| Propiedad | Valor |
|---|---|
| Encabezado de firma | `X-Webhook-Signature` |
| Formato de la firma | `sha256=<hex>` |
| Encabezado complementario | `X-Webhook-Timestamp` (segundos epoch unix, string) |
| Algoritmo | `HMAC-SHA256` |
| Material firmado | `"{X-Webhook-Timestamp}." + cuerpo`, sobre los **mismos bytes** que viajan en la solicitud (JSON compacto, UTF-8) |
| Cálculo | Una vez por evento: los reintentos llevan la misma firma y el mismo timestamp |
| Ventana de repetición | 5 minutos de desfase máximo de `X-Webhook-Timestamp`, comprobados por su verificador |

:::warning[Verifique sobre los bytes que recibe]
Lo que firmamos es exactamente el cuerpo que le llega. Calcule el HMAC sobre esos bytes crudos, antes de
parsearlos. No intente reconstruir el JSON: cualquier re-serialización (orden de las claves, espacios, escape de
caracteres no ASCII) rompe la firma.
:::

## Verificación — Python (hmac)

```python
import hmac
import hashlib
import time

REPLAY_WINDOW_SECONDS = 300  # 5 minutos

def verify_webhook(
    *,
    body: bytes,                   # cuerpo crudo de la solicitud
    signature_header: str,         # valor de X-Webhook-Signature
    timestamp_header: str,         # valor de X-Webhook-Timestamp
    secret: str,                   # tu webhook_secret
) -> bool:
    if not signature_header.startswith("sha256="):
        return False

    # Rechaza lo que esté fuera de la ventana de repetición
    try:
        ts = int(timestamp_header)
    except ValueError:
        return False
    if abs(time.time() - ts) > REPLAY_WINDOW_SECONDS:
        return False

    expected = signature_header.removeprefix("sha256=")
    signed = f"{timestamp_header}.".encode() + body
    actual = hmac.new(secret.encode(), signed, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, actual)
```

## Verificación — TypeScript (Node 22+)

```ts
import { createHmac, timingSafeEqual } from "node:crypto";

const REPLAY_WINDOW_SECONDS = 300;

export function verifyWebhook(opts: {
  body: Buffer;
  signatureHeader: string;
  timestampHeader: string;
  secret: string;
}): boolean {
  const { body, signatureHeader, timestampHeader, secret } = opts;
  if (!signatureHeader.startsWith("sha256=")) return false;

  const ts = Number.parseInt(timestampHeader, 10);
  if (!Number.isFinite(ts)) return false;
  if (Math.abs(Date.now() / 1000 - ts) > REPLAY_WINDOW_SECONDS) return false;

  const expected = signatureHeader.slice("sha256=".length);
  const signed = Buffer.concat([Buffer.from(`${timestampHeader}.`), body]);
  const actual = createHmac("sha256", secret).update(signed).digest("hex");

  return (
    expected.length === actual.length &&
    timingSafeEqual(Buffer.from(expected), Buffer.from(actual))
  );
}
```

## Verificación — PHP

```php
<?php
const REPLAY_WINDOW_SECONDS = 300;

function verifyWebhook(string $rawBody, string $signatureHeader, string $timestampHeader, string $secret): bool {
    if (strpos($signatureHeader, 'sha256=') !== 0) {
        return false;
    }
    $ts = (int) $timestampHeader;
    if (abs(time() - $ts) > REPLAY_WINDOW_SECONDS) {
        return false;
    }

    $expected = substr($signatureHeader, strlen('sha256='));
    $signed = $timestampHeader . '.' . $rawBody;
    $actual = hash_hmac('sha256', $signed, $secret);

    return hash_equals($expected, $actual);
}
```

## Modos de falla comunes

- **Re-stringificar el cuerpo antes de verificar** — consulte la advertencia de arriba.
- **Recortar el prefijo `sha256=` en el lugar equivocado** — quítelo de
  `signature_header`, no del valor calculado.
- **Sin ventana de repetición** — sin una comprobación de timestamp, un atacante
  puede repetir indefinidamente una entrega capturada.
- **Comparación de strings en lugar de comparación de tiempo constante** — use
  `hmac.compare_digest`, `timingSafeEqual`, `hash_equals`.

## Rotación del secreto {#secret-rotation}

:::danger[El secreto se muestra una sola vez]
`POST /webhooks/config/rotate-secret` devuelve el nuevo `webhook_secret` una sola vez y no hay forma de volver a
leerlo. Si pierde la respuesta, tiene que rotar de nuevo. Guarde la respuesta en su gestor de secretos antes de
cualquier otra acción.
:::

La rotación la hace un administrador del espacio de trabajo (ver
[Webhooks → Paso 7](/docs/saas/1platform-api/plataforma/webhooks)). Un procedimiento seguro:

1. Llame a `POST /webhooks/config/rotate-secret` desde un script que escriba la respuesta directamente en su gestor
   de secretos.
2. Despliegue el secreto nuevo en su verificador y **conserve el anterior unos minutos** (acepte cualquiera de los
   dos). Los eventos firmados antes de la rotación siguen reintentándose con la firma vieja durante alrededor de un
   minuto.
3. Pasados esos minutos, elimine el secreto anterior del verificador.
