<p className="lead">Integre con su agente de código: consulte la documentación mediante el MCP y use los prompts y las skills de cada producto.</p>

El contrato es el de la [Referencia de API](/api-reference/1platform-api).

## Antes de empezar {#antes-de-empezar}

- **Claves.** Solicite las de aplicación (`ak-…`) y usuario (`sk-…`) en Panel → API, según [Inicio rápido](/docs/saas/1platform-api/inicio-rapido#claves).
- **Entorno.** Use **QA** por defecto; solicite acceso a su contacto comercial. Producción requiere su indicación explícita y claves propias.
- **Secretos.** Guarde las claves en variables de entorno de su máquina o servidor, nunca en código, navegador o conversaciones.

## Documentación en Markdown {#documentacion-en-markdown}

Agregue `.md` a la URL de una página. Consulte el [índice](pathname:///llms.txt), el
[archivo completo](pathname:///llms-full.txt) o el [OpenAPI](pathname:///openapi/1platform-api.json).

```bash
curl -s https://developer.1platform.pro/llms.txt | head -20
curl -s https://developer.1platform.pro/docs/saas/1platform-api/inicio-rapido.md
```

## Skills por producto {#skills}

El [catálogo de Agent Skills](pathname:///skills/index.json) incluye `1platform-hub` (autenticación, entornos
y errores) y recetas por producto. Instálelas en Claude Code:

```bash
for skill in 1platform-hub agentes-de-ia analitica contenido correo-transaccional dominios-y-correo envios facturacion-electronica links-de-pago mcp pagos-en-linea publicidad retiros sitios-web suscripciones telemetria terminal-de-tarjetas ventas webhooks; do
  mkdir -p ".claude/skills/$skill"
  curl -fsSL "https://developer.1platform.pro/skills/$skill/SKILL.md" -o ".claude/skills/$skill/SKILL.md"
done
```

Otros agentes que leen Agent Skills usan la misma estructura en su propia carpeta de skills.

## Mantener vigente la integración

El MCP lee el Markdown y el OpenAPI publicados aquí, con caché de diez minutos. Un cambio local no actualiza
el servidor alojado. Si falta una operación, compruebe la versión y reporte la discrepancia. Estas herramientas
documentan Core; Atlas conserva su contrato independiente.

## Servidor MCP {#mcp}

Sin claves, el MCP ofrece `docs_search`, `docs_get_page` y `api_get_operation`. Con claves, añade herramientas
por producto (*toolset*):

| Toolset | Qué puede hacer el agente |
|---|---|
| `cuenta` | Perfil, saldo, consumo, comercios y avisos. Siempre activo: de aquí sale el `businessId` |
| `pagos` | Links de pago (listar, ver, crear y cancelar) y transacciones |
| `retiros` | Saldo retirable, movimientos y retiros (sólo lectura) |
| `suscripciones` | Planes, suscripciones y clientes |
| `terminal` | Solicitudes de terminal de tarjetas y su estado |
| `facturacion` | Facturas electrónicas (sólo lectura) |
| `envios` | Envíos (sólo lectura) |
| `sitios` | Sitios, artículos, trabajos de generación, categorías y rendimiento de búsqueda |
| `analitica` | Métricas del sitio, ingresos y alertas de anuncios, mapas de calor |
| `correo` | Correo transaccional (remitentes, plantillas, cupos, mensajes) y conversaciones del correo del negocio |
| `dominios` | Dominios, disponibilidad, precios, transferencias y registros de correo (sólo lectura) |
| `telemetria` | Proyectos, errores, registros, rendimiento y uso; marcar un error como resuelto o ignorado |
| `ventas` | Preparación, canales, ofertas, prospectos, tablero y reporte |
| `agentes` | Agentes, catálogo, herramientas, presupuesto, ejecuciones y acciones; detener una ejecución |

Las escrituras (crear y cancelar un link de pago, detener una ejecución de un agente y cambiar el estado de un error)
no mueven dinero y el cliente pide confirmación antes de ejecutarlas. Ninguna herramienta cobra saldo, emite
documentos fiscales, mueve dinero ni envía mensajes a terceros: eso se hace con la API, siguiendo la skill de cada
producto.

Por defecto el servidor lista todos los toolsets. Si su cliente admite pocas herramientas, elija los productos que usa
con la variable `ONEPLATFORM_TOOLSETS` (paquete local) o la cabecera `X-OnePlatform-Toolsets` (servidor alojado), por
ejemplo `pagos,envios`. `cuenta` y la documentación se listan siempre.

Puede correrlo en su máquina como paquete npm (`@oneplatformlabs/mcp`), que lee las claves de las variables
`ONEPLATFORM_APP_KEY` y `ONEPLATFORM_USER_KEY` (`ONEPLATFORM_ENV` vale `qa` salvo que lo cambie a `prod`), o
conectar el agente al [servidor alojado](#alojado), sin instalar nada.

### Claude Code {#claude-code}

```bash
claude mcp add oneplatform \
  --env ONEPLATFORM_APP_KEY="$ONEPLATFORM_APP_KEY" \
  --env ONEPLATFORM_USER_KEY="$ONEPLATFORM_USER_KEY" \
  -- npx -y @oneplatformlabs/mcp
```

Para listar sólo algunos productos, agregue `--env ONEPLATFORM_TOOLSETS=pagos,envios` al mismo comando.

La configuración equivalente para el archivo `.mcp.json` del proyecto está en
[`/mcp/claude-code.json`](pathname:///mcp/claude-code.json).

### Cursor {#cursor}

Copie [`/mcp/cursor.json`](pathname:///mcp/cursor.json) a `.cursor/mcp.json` en la raíz del proyecto y reemplace
las claves de ejemplo por variables de su entorno:

```bash
mkdir -p .cursor
curl -fsSL https://developer.1platform.pro/mcp/cursor.json -o .cursor/mcp.json
```

### VS Code {#vscode}

Copie [`/mcp/vscode.json`](pathname:///mcp/vscode.json) a `.vscode/mcp.json`:

```bash
mkdir -p .vscode
curl -fsSL https://developer.1platform.pro/mcp/vscode.json -o .vscode/mcp.json
```

### Servidor alojado {#alojado}

El servidor alojado no requiere instalar nada: recibe sus claves en cada solicitud y no las guarda.

| URL | API |
|---|---|
| `https://mcp-qa.1platform.pro/mcp` | QA |
| `https://mcp.1platform.pro/mcp` | Producción |

La URL decide el entorno; ninguna cabecera ni parámetro lo cambia.

```bash
claude mcp add --transport http oneplatform https://mcp-qa.1platform.pro/mcp \
  --header "X-OnePlatform-App-Key: $ONEPLATFORM_APP_KEY" \
  --header "X-OnePlatform-User-Key: $ONEPLATFORM_USER_KEY" \
  --header "X-OnePlatform-Toolsets: pagos,envios"
```

La última cabecera es opcional: sin ella se listan todos los toolsets.

En otros clientes que aceptan servidores remotos por HTTP, use la misma URL con las cabeceras
`X-OnePlatform-App-Key` y `X-OnePlatform-User-Key`. El servidor admite 30 solicitudes por minuto desde una misma IP
y 120 por par de claves.

### Cómo se comporta {#como-se-comporta}

- El servidor canjea sus claves por los dos tokens y los reutiliza hasta antes de que venzan.
- Antes de operar sobre un comercio, el agente llama a `listBusinessesForUser` para obtener el `businessId`.
- Un `403` con `module_disabled` indica un módulo apagado en su espacio de trabajo, no una falla del servidor.
- Las respuestas llegan tal como las devuelve la API, con su código de estado, y se marcan como datos: pueden traer
  textos de terceros que el agente no debe tratar como instrucciones.
