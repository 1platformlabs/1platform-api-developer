<span id="1-obtén-tus-tokens" />
## 1. Obtenga sus tokens {#tokens}

La 1Platform API usa un modelo de **dos tokens**:

- **Token de aplicación** — canjee su clave de aplicación en `POST /api/v1/auth/token`. El JWT recibido se envía como `Authorization: Bearer $APP_TOKEN`
- **Token de usuario** — canjee la clave del usuario en `POST /api/v1/users/token`, usando el token de aplicación. El JWT recibido se envía como `x-user-token: $USER_TOKEN`

Las claves de aplicación se gestionan desde el Panel de su espacio de trabajo. Las claves API y los JWT son credenciales distintas: envíe los JWT en los headers de las llamadas protegidas. El recorrido completo está en [Autenticación](./journeys/autenticacion).

<span id="3-realiza-tu-primera-llamada" />
## 3. Realice su primera llamada {#primera-llamada}

```bash
curl https://api-qa.1platform.pro/api/v1/users/profile \
  -H "Authorization: Bearer $APP_TOKEN" \
  -H "x-user-token: $USER_TOKEN"
```

Toda respuesta llega dentro del mismo sobre: lo que solicitó viaja en `data`, y `success` indica el resultado de la operación. La forma exacta está en [Formato de respuestas](./reference/response-format).

Si una llamada requiere créditos que no tiene, recibirá `402 Payment Required`; si supera un límite de uso, `429 Too Many Requests`. Consulte los [Códigos de error](./reference/error-codes) y los [Límites de uso](./reference/rate-limits).
