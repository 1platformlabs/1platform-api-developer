# Capacidades

Los [Recorridos](./journeys/autenticacion) cubren las integraciones que tienen un orden obligatorio real. El resto de
la API — todo lo que es CRUD auto-contenido — **sigue publicado y documentado**, sólo que en la
[referencia interactiva](/api-reference/1platform-api) en vez de en una página de prosa que puede
desincronizarse. Esta tabla es el mapa: cada fila te lleva directo a la sección de la referencia.

| Capacidad | Qué es | Referencia |
|---|---|---|
| Registros de actividad | Consultar y purgar el historial de acciones de tu aplicación. | [Activity Logs →](/api-reference/1platform-api#tag/activity-logs) |
| Administración del tenant | Gestión de usuarios, métricas y operaciones administrativas de tu espacio. | [Tenant Admin →](/api-reference/1platform-api#tag/tenant-admin) |
| Panel del dashboard | Bootstrap e internacionalización del panel white-label. | [Dashboard →](/api-reference/1platform-api#tag/dashboard) |
| Configuración del dashboard | Lectura y escritura de ajustes por clave del panel. | [Dashboard Settings →](/api-reference/1platform-api#tag/dashboard-settings) |
| Gestión de dominios | Compra, transferencia, DNS y contactos de dominios. | [Domains →](/api-reference/1platform-api#tag/domains) |
| Integraciones externas | Publicar en Publisuites y verificar propiedad en Search Console. | [Link Building & Search Console →](/api-reference/1platform-api#tag/link-building-search-console) |
| Sitios web | Alta y gestión de los sitios de un usuario — prerrequisito de Analytics, AdSense y las integraciones externas (ver [Convenciones](./reference/convenciones)). | [Websites →](/api-reference/1platform-api#tag/websites) |
| Notificaciones | Bandeja de notificaciones del usuario. | [Notifications →](/api-reference/1platform-api#tag/notifications) |
| Programa de referidos | Consultar código y estado de referidos. | [Referrals →](/api-reference/1platform-api#tag/referrals) |
| Soporte | Preguntas frecuentes y tickets de soporte. | [Support →](/api-reference/1platform-api#tag/support) |
| Tareas | Gestión de tareas del usuario. | [Tasks →](/api-reference/1platform-api#tag/tasks) |
| Envíos | Registrar, despachar y seguir los envíos de un comercio. Con flota propia funciona de punta a punta; el despacho por mensajería se configura por inquilino. Incluye el seguimiento público sin credencial. | [Deliveries →](/api-reference/1platform-api#tag/deliveries) |
| Publicidad | Campañas pagadas con el saldo del espacio de trabajo: conectar la marca, armar la campaña, fondearla y leer resultados. Se habilita por espacio de trabajo. | [Ads →](/api-reference/1platform-api#tag/ads) |
| Enlaces de cobro | Emitir enlaces para cobrarle a alguien que no es usuario de 1Platform. El enlace público no lleva credencial: el token es la capacidad. | [Payment Links →](/api-reference/1platform-api#tag/payment-links) |
| Terminales de pago | Solicitar una terminal para cobrar con tarjeta presente, adjuntar documentación, seguir la solicitud y recibir su resolución. | [Payment Terminals →](/api-reference/1platform-api#tag/payment-terminals) |
| Suscripciones | Dos cosas bajo el mismo tag: los planes de suscripción, clientes y suscripciones **de tu comercio** (la mayor parte de sus operaciones), y la consulta de **tu propio** plan con 1Platform. | [Subscriptions →](/api-reference/1platform-api#tag/subscriptions) |

:::note
La descripción del tag **Subscriptions** en la referencia habla sólo de consultar
un plan y su estado. Eso describe cuatro de sus dieciocho operaciones: las otras
catorce son las del comercio (planes, clientes, invitaciones y suscripciones).
La fila de arriba describe lo que el tag realmente contiene; la descripción del
tag está reportada para corregirse en el repositorio de la API.
:::
